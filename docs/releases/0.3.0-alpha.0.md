# SkyKit 0.3.0-alpha.0 package batch

This alpha makes the current SkyKit composition APIs and contextual spatial
foundation available to independent consumers. Install exact versions for
integration work; the public website continues to use stable 0.2.0.

| Package | Version |
| --- | --- |
| `@found-in-space/skykit` | `0.3.0-alpha.0` |

Anchored-image remains at 0.2.0, and optional touch-os integration uses stable
0.3.0. Changed packages publish under `alpha`; existing stable `latest` tags
remain unchanged.

Spatial now requires explicit coordinate spaces and physical units for poses,
aims, routes, paths and motion. Presentation scale is independent from physical
conversion. Shared anchored transforms rebase before scaling, and generic math
supports both stellar and Solar System consumers. See the
[spatial contract](../../packages/spatial/api-contract.md) for the breaking API
and migration rules. Spatial alpha.0 was a local packed validation version;
Changesets advances it to alpha.1 for this coordinated batch.

SkyKit preserves its public parsec catalog/view fields through explicit spatial
adapters. The batch also includes lane-aware navigation, product registries,
pointer orbit controls, the stable touch-os bridge, STAR v2 support, debounced
star demand and custom renderer cell attributes. Package changelogs record the
individual changes. Spherical preload radii now convert from declared units
to catalog parsecs, with inclusion checks across both unit systems.

Consumers using SkyKit with star packages should update their direct pins to
this batch together. Prereleases do not satisfy ordinary stable peer ranges:
adapters with a SkyKit peer must explicitly admit `0.3.0-alpha.0`. Keep Three.js
resolution consistent with the consuming application's renderer setup.
