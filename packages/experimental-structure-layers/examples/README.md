# Experimental Structure Layer Lessons

The old dust and H-alpha demos should move here as preservation lessons when
they are rebuilt against alpha package APIs.

This package is intentionally experimental. Examples here may teach:

- loading McCallum H-alpha tiled volumes,
- loading Dust Map NG volumes,
- mounting structural layers into SkyKit scale-banded roots,
- keeping structural products outside core `@found-in-space/skykit`.

Do not import old root `src/` demo wrappers when adding these lessons.
